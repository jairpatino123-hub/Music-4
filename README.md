# Music-4 — Synthetiq YouTube Music Connector

Repository layout prepared for the Synthetiq Music connector catalogue format.

- `catalogue.json` — connector catalogue and SHA-256 package reference
- `modules/YT-Music-Direct-1.0.1/` — module source
- `packages/YT-Music-Direct-1.0.1.zip` — immutable versioned package

Import the repository URL in Synthetiq Music under Settings → Sources → Advanced.

This connector is for YouTube Music track discovery/metadata. It does not contain downloaded audio, reusable media URLs, credentials, or request headers.
